# 00_PROJECT_INIT｜Bright Velo L0 概念站

## 项目一句话定位

面向骑行、休闲与团体旅客的高端高地酒店首页概念，突出住宿、Basils 餐饮与团体体验，并保留现有外部预订链。

## 当前授权

用户于 2026-08-14 授权“帮他做一个精美的网站出来”。本实例只构建本地 L0 静态概念，不代表客户确认、生产发布、RMS/OpenTable 接入、内容上线或付款授权。

## 一期范围

- 一页响应式首页；
- 原创 CSS 视觉占位与原创短文案；
- 现有公开 RMS、Basils、官网联系页外链；
- 本地构建与验证。

## 不做范围

- 不使用客户 Logo、照片、视频或原文案；
- 不创建真实表单、支付、后台、账号、数据库或 API；
- 不修改 RMS、OpenTable、Wix 或任何外部系统；
- 不部署、不联系客户、不主张生产可用。

## 已知风险与待确认

- 品牌、视觉、文案、版权、实际页面范围、Wix 控制权、预算、验收人均待客户确认；
- L0 概念不能作为真实住宿库存、价格、活动或餐饮营业信息的来源。
