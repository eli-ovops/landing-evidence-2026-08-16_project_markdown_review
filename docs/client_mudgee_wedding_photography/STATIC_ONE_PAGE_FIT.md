# 纯静态单页适配判断

## 门槛矩阵

| 维度 | 结论 | 说明 |
|---|---|---|
| Static HTML/CSS/少量 JS only | `技术上 YES；商业替代 NO` | 固定品牌、简介、服务类别、精选作品、信任、FAQ、电话/邮箱可以静态完成；但替代当前 Pixieset 会丢失丰富作品与图库价值。 |
| Backend dependency | `NONE（仅限新静态页本身）` | 可只用 `tel:`、`mailto:`、IG/现有 Pixieset 外链；不做表单、数据库、CMS、预约或支付。 |
| Content stability | `CONDITIONAL / MEDIUM` | 经历、方法、服务边界、资格、固定评价较稳定；摄影作品、奖项、套餐和活动图库具有持续更新价值。 |
| Ongoing content owner | `CLIENT` | Col/现供应商负责作品、奖项、套餐、档期与社交；我方不持续维护。 |
| External-system boundary | `Pixieset + Instagram/Facebook only` | 只作客户已有外部系统；我方不登录、不配置、不维护、不复制其内容。 |
| 单页外链前独立价值 | `可设计成立，但现有站已实现` | 固定精选作品可在外链前完成品牌、信任、服务与联系决策；新增价值不足。 |

## 摄影作品是否违反“无内容责任”

### 可以不违反的窄条件

- 只使用客户书面确认可商用的 6–10 张“长期代表作”，不承诺最新。
- 不展示日期驱动新闻、实时奖项 feed、实时档期或不断变化的套餐价格。
- 页面写清联系后确认报价/档期；客户自行维护 IG/Pixieset。
- 客户承担未来换图、版权、人物肖像许可与内容准确性；任何后续改版另行授权/报价。

### 会违反或削弱产品门槛的条件

- 客户要求页面持续展示“最近婚礼”、最新获奖、每场活动图库或实时作品 feed。
- 页面必须同步 Pixieset、社交、套餐或档期才能可信。
- 我方被期待定期替换照片、处理相册、发布奖项或维护客户隐私授权。

### 本商户的实际判断

当前数字资产把近期作品与多页画廊作为重要能力，且 2026 年持续更新。固定静态精选集虽可独立成立，却更适合作为精简入口，不适合替代当前完整站。对“第一笔 AU$800 静态单页”的战略适配为 `Low`。

## 现有系统边界

- Pixieset：现有网站、作品页、客户图库、套餐、评价、联系表单；不登录、不配置、不迁移。
- Instagram/Facebook：只外链；不抓 feed、不管理社交。
- 旧站第三方表单：不提交、不复制、不承接服务端处理。
- 域名/DNS：控制权未知；任何修正、重定向或切换均需客户和现供应商明确授权，不属于本轮。

## 概念性 Cold Demo 假设（未来获授权才可）

Demo 不应证明“我们能做更漂亮的摄影页”，而应只证明：

> 一个不复制素材的私有静态概念，能否把旧品牌入口统一到当前 Col Boyd Photography 身份，在一屏内说明服务对象、核心信任、固定代表作结构与单一联系动作，同时明确把最新图库留在客户现有 Pixieset。

验证点：

1. 品牌统一是否比旧站更清楚，而不是与当前站竞争。
2. 390px 首屏能否直接显示电话/邮件 CTA。
3. 固定精选作品占位是否足以完成信任，而无需持续更新。

但当前不满足 Demo 入口：尚未证明客户想替换/整合，且已有满意供应商证据。因此本轮不得制作页面、截图拼贴、代码或部署。

## 推翻 DROP 的必要条件

必须同时获得客户原始确认：

- 旧域名仍有重要流量且当前造成可量化询盘损失；
- 当前 Pixieset 站不能或不愿继续使用，或客户明确要一个独立静态入口；
- 客户控制目标域名/发布权限，现供应商边界已处理；
- 客户接受固定精选作品与自行维护最新内容；
- AU$800 预算与验收范围明确。

在这些条件前，静态适配只能标“技术可行”，不能标“商业可售”。
