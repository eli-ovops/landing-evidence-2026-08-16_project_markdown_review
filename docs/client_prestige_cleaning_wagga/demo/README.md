# Prestige Cleaning Wagga — local static concept

Open `index.html` locally, or serve this directory with any static local web server. This is a private L0 visual concept, not a customer website or a deployment package.

The active visual assets are original AI-generated concept images: `assets/hero-commercial-washing-v2.png` plus one distinct image for each service card (`service-office-medical-v1.png`, `service-retail-hospitality-v1.png`, `service-exterior-presentation-v1.png`, and `service-property-maintenance-v1.png`). Each is used once only. They require human rights and final-use approval before any external publication.
