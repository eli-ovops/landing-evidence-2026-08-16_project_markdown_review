# Always Love Celebrant Services · Private L0 Demo

This is a local-only static concept. It is not approved for publication and does not modify the current website.

## Local commands

```bash
corepack pnpm@10.34.5 install --frozen-lockfile
corepack pnpm@10.34.5 build
corepack pnpm@10.34.5 preview --host 127.0.0.1
```

Open the `http://127.0.0.1:4173/` address printed by the preview command for development. For a direct local preview, open `dist/index.html`; the production CSS and JavaScript are inlined so this built file also works through `file://`. Do not open the source-level `demo/index.html` directly.

## Boundaries

- No CMS, database, login, form handler, booking, payment, or availability feed.
- Contact actions use the public email address and phone number.
- Original-site imagery is used only in this private concept. Publication requires documented copyright and personality-rights confirmation.
