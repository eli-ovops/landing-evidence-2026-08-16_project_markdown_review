# Cherry Walk Cafe — L0 local concept

## Scope

Original local-only landing-page mock built after the user explicitly asked to make a beautiful website on 2026-08-14.

- Level: L0 mock only.
- No deployment, no customer contact, no live booking integration, no database, no authentication, no tracking.
- No copied client logo, photography, menu copy, testimonials or other merchant assets.
- `src/assets/cherry-walk-hero-original.png` is an original AI-generated visual. It is a concept asset only; commercial use still requires owner approval.

## Known facts intentionally held back

Research evidence identifies conflicting address, opening-hour and booking information. The UI therefore shows only Bright, Victoria and routes visit actions to a transparency panel. Do not replace these controls with an address, hours, phone or booking URL until the owner confirms canonical details.

## Local run

```bash
corepack pnpm install
corepack pnpm dev
```

## Build

```bash
corepack pnpm build
```

## Required owner confirmation before any client-facing use

1. Canonical street address and accessibility wording.
2. Weekly and public-holiday opening hours.
3. Approved booking flow or an intentional no-booking alternative.
4. Final menu, pricing, dietary claims and social proof.
5. Permission for final visual assets and publication.
